# AI 서비스 기획 강의용 웹앱 PRD

## 목표와 사용자

강사가 수업 중 한 가지 AI 서비스 기획 사례를 화면에 공유하며 문제 정의부터 효과 검증까지 설명한다. 강사가 화면을 조작하고 수강생은 데모를 보며 AI와 사람의 역할을 구분하고 효과를 검증하는 방법을 익힌다.

## 첫 버전 범위

AI 고객 문의 답변 도우미 사례 한 개를 네 단계와 요약 화면으로 제공한다. 수업용 가상 문의와 정책, 미리 작성한 AI 출력 예시를 사용한다. 실시간 AI 호출, 로그인, 수강생 입력·저장, 사례 편집은 이후 범위로 둔다.

## 화면과 콘텐츠

| 화면 | 표시할 내용 | 강의에서 짚을 질문 |
| --- | --- | --- |
| 1. 사용자와 문제 | 상담원이 문의 확인 → 반품 정책 검색 → 답변 작성 순서로 일하는 과정을 보여준다. 정책 검색과 답변 작성이 반복되는 지점을 강조한다. | 누구의 어떤 작업을 줄이려는가? |
| 2. AI의 역할 | 정상 문의, 적용 정책 문구, AI 답변 초안을 나란히 보여준다. 초안에서 어떤 판단이 정책 문구에 근거하는지 드러낸다. | AI는 무엇을 받아 무엇을 돌려주는가? |
| 3. 실패 시 대응 | 반품 가능 여부를 판단하는 데 필요한 정보가 없는 문의와 AI의 확인 요청을 보여준다. 상담원이 추가 정보를 확인하고 최종 답변을 발송하는 흐름을 표시한다. | AI가 판단할 수 없을 때 누가 무엇을 확인하는가? |
| 4. 효과 검증 | 같은 문의를 수동 방식과 AI 보조 방식으로 처리해 소요 시간과 정책 위반율을 비교하는 방법을 보여준다. | 빨라졌는지, 답변 품질은 유지되는지 어떻게 확인하는가? |
| 요약 | 사용자 문제, AI의 역할, 상담원의 역할, 검증 방법을 한 화면에 정리한다. | 이 판단을 다른 AI 서비스 사례에 어떻게 적용할 수 있는가? |

## 데모용 예시

**가상 반품 정책** — 미개봉 상품은 수령 후 7일 이내에 반품을 신청할 수 있다. 수령일이나 개봉 여부를 모르면 해당 정보를 먼저 확인한다.

| 구분 | 고객 문의 | AI 출력 예시 | 상담원 조치 |
| --- | --- | --- | --- |
| 정상 | “3일 전에 받았고 아직 개봉하지 않았어요. 반품되나요?” | “미개봉 상품은 수령 후 7일 이내에 반품을 신청할 수 있습니다.” 근거로 해당 정책 문구를 표시한다. | 초안이 정책과 고객 문의에 맞는지 확인한 뒤 발송한다. |
| 추가 확인 | “지난주에 받았는데 반품되나요?” | “확인 필요 — 정확한 수령일과 개봉 여부가 필요합니다.” | 두 정보를 확인한 뒤 반품 가능 여부를 안내한다. |

검증 화면에서는 두 방식 모두 문의를 연 시점부터 발송 가능한 답변을 확정한 시점까지 잰다. 정책 위반율은 검토한 최종 답변 중 정책에 어긋난 답변의 비율로 계산한다. 정상 문의와 추가 확인이 필요한 문의를 비교에 포함한다.

## 기능 요구사항과 완료 기준

| 요구사항 | 완료 기준 |
| --- | --- |
| 시작 및 진행 표시 | 앱을 열면 첫 단계가 표시된다. 단계 화면에는 현재 단계 이름과 전체 네 단계 중 위치가 표시된다. 요약 화면에는 요약 제목이 표시된다. |
| 이전·다음 이동 | 둘째 단계부터 이전 버튼으로 직전 화면으로 돌아갈 수 있다. 넷째 단계에서 다음을 누르면 요약이 열리고, 요약의 이전 버튼은 넷째 단계로 돌아간다. 첫 단계에는 이전 이동이 없고, 요약에는 다음 이동이 없다. |
| 반복 시연 | 요약의 ‘처음부터’ 버튼을 누르면 첫 단계로 돌아간다. |
| 예시와 요약 | 정상 문의 화면에서 문의·정책·초안을 구분할 수 있고, 추가 확인 화면에서 부족한 정보와 상담원 조치를 확인할 수 있다. 요약에는 네 가지 기획 결정이 모두 표시된다. |
| 강의 화면 가독성 | 화면 공유에 사용할 1280 × 720 크기의 브라우저 뷰포트에서 단계 제목, 핵심 문장, 이동 버튼이 가로 스크롤 없이 보인다. |
| 키보드 조작 | Tab으로 이동 버튼에 접근하고 Enter 또는 Space로 실행할 수 있다. 현재 선택된 버튼이 시각적으로 구분된다. |

## 수업에서 확인할 결과

강사가 화면 공유 상태에서 첫 단계부터 요약까지 시연한다. 데모 직후 수강생에게 AI가 맡는 일, 추가 확인이 필요한 상황에서 상담원이 하는 일, 효과를 평가할 지표를 사례에 근거해 설명하도록 묻는다.
